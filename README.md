# Fundamentos de Testes — QA

Repositório com meus estudos em Qualidade de Software, baseado no 
CTFL 4.0 (ISTQB), BDD/Gherkin, Postman e SQL. Aqui estão resumos, 
anotações, exercícios e evidências práticas do meu aprendizado em QA.

## 📚 Conteúdo

| Pasta | Descrição |
|---|---|
| [01 — Fundamentos](./01-fundamentos/) | Conceitos básicos: erro, defeito, falha, ciclo de vida, tipos de teste |
| [02 — Técnicas de Teste](./02-tecnicas-de-teste/) | Particionamento de equivalência, valores limite, análise de design |
| [03 — Teste Estático](./03-teste-estatico/) | Revisões, inspeções e análise estática |
| [04 — Gerenciamento](./04-gerenciamento/) | Planejamento, monitoramento, riscos e ciclo de vida do bug |
| [05 — Ferramentas](./05-ferramentas/) | Visão geral de ferramentas de teste |
| [06 — BDD e Gherkin](./06-bdd-gherkin/) | Behavior-Driven Development, sintaxe Gherkin e Cucumber |
| [07 — Postman](./07-postman/) | Testes de API com Postman + evidências de execução |
| [08 — SQL](./08-sql/) | Exercícios de consultas, validação de dados |
| [09 — Exercícios](./09-exercicios/) | Exercícios práticos e portfólio de QA |
